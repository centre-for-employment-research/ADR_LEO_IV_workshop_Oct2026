# Using distance as an Instrumental Variable in LEO to analyse post-16 transitions of disadvantaged young people

As part of the [ADR England Research Community Catalyst: Youth Transitions](https://www.adruk.org/learning-hub/user-groups-communities/adr-england-research-community-catalyst-youth-transitions/) project, the University of Westminster is running a face-to-face event on 22nd October to support you in your evaluations using ADR admin datasets. The session will describe the step-by-step data and analysis procedures needed to study post-16 transitions using distance as an Instrumental Variable in the [Longitudinal Education Outcomes (LEO)](https://www.adruk.org/data-access/flagship-datasets/longitudinal-education-outcomes/) dataset.

The session will be led by Professor Peter Urwin and focus on practical insights, drawing on existing work that evaluates the impact of post-16 learning pathways – helping attendees carry out their own analyses. The session will include presentations and workshop activities that allow attendees to further interrogate coding, data and method challenges; and access support from session leads on what this means for their own evaluation challenges. We will also consider the challenges of interpreting findings for policy development and consider enhancements to method that can provide further insight.
